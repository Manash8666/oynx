Self-Healing Execution Loop

Zero Broken Code. 4-Stage Verification.

How Onyx eliminates the hallucinated errors, compile breaks, and runtime crashes that plague other AI coding assistants.

01

Ingest & AST Map

Constructs a full semantic knowledge graph of your project, calculating call graphs and topological dependencies before generating code.

02

In-Process Compile

Language servers compile the proposed diff in-memory. Missing exports, bad typings, and syntax errors are blocked before touching disk.

03

Surgical Micro-Patch

Semantic AST slicer replaces only the targeted function or block, completely avoiding whole-file overwrites and accidental data loss.

04

PTY Rollback Checkpoint

Atomic git snapshots created prior to execution. If test suites fail, the self-healing loop corrects the code or performs an instant 1-click rollback.
